# 粒子运动 · Particle Motion

一个用 **p5.js** 写的粒子运动实验：15 个彩色圆在画布中运动、撞墙反弹，鼠标横向移动控制整体速度、纵向移动控制粒子大小，点击画面随机重生一批粒子。

> 在线预览：**https://wangzixuanshijiu.github.io/particle-motion/**

## 交互方式

| 操作 | 效果 |
|---|---|
| 鼠标左右移动 | 粒子整体速度在 0.5 ~ 2.5 倍之间变化 |
| 鼠标上下移动 | 粒子直径在 0.7 ~ 1.5 倍之间变化 |
| 鼠标点击 | 清空并按新随机值重新生成 15 个粒子 |

| 文件 | 说明 |

## 实现要点

- `colorMode(HSB, 360, 100, 100, 100)`：色相 180°~360°（青→紫→品红），饱和度 85，亮度 100
- `background(220, 70, 8, 12)`：极低 alpha 的背景填充，形成粒子拖尾的残影效果
- 每个粒子有独立的速度 `vx / vy`、半径 `r`（8~30）和色相 `h`（180~360）
- 边界碰撞：`p.x < p.r/2` 或 `p.x > width - p.r/2` 时速度反向，粒子完整留在画布内
- `map()` 把鼠标坐标映射到速度与缩放系数，实现跟随交互

## 运行方式

直接双击 `index.html` 即可（引擎已本地化，无需联网）。
或启动本地服务器：

```bash
python -m http.server 8000
# 打开 http://localhost:8000
```
